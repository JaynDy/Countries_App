# AppCountries

The project is built using pure HTML, CSS, and JavaScript.
The app has a responsive layout with media queries and uses Grid and Flexbox to arrange country cards flexibly.
JavaScript (ES6+) is used for searching countries, filtering by region, and switching between light and dark themes.

Проект создан с использованием чистого HTML, CSS и JavaScript. 
Приложение имеет адаптивный дизайн с медиазапросами.
Используется Grid и Flexbox для гибкого размещения карточек стран. 
JavaScript (ES6+) используется для поиска стран, фильтрации по регионам и переключения между светлой и темной темами.
